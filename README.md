# Infinity Maipú · Web 3D

Web pública de **Infinity Maipú** (canchas de fútbol 7 y 9, quincho, zona de eventos y cafetería en 4 Poniente 200, Maipú) con una cancha 3D interactiva hecha con three.js.

## Contenido

| Ruta | Qué es |
|---|---|
| `index.html` | La página completa: reserva de cancha, celebraciones, videos, preguntas frecuentes y Club Infinity |
| `media/` | Logo, 3 videos y sus portadas |

## Cómo verla

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático, por ejemplo `python3 -m http.server`.

## Estado

Versión de ejemplo: la reserva, los pagos y las cuentas se simulan en el navegador (`localStorage`). Nada se cobra ni se envía. La especificación del backend está en el documento "Infinity Maipú · Especificación técnica del backend".
